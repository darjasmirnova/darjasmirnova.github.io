# 🐱 Галерея Котов - Web Application

Веб приложение на Node.js для безмозглого просмотра красивых котов из The Cat API!

## Описание

Приложение получает данные о котах из публичного API [The Cat API](https://thecatapi.com) и отображает их в виде красивых карточек с изображениями и описаниями пород.

## Требования

- Node.js (v14 или выше)
- npm (поставляется с Node.js)

## Установка

1. Установите зависимости:
```bash
npm install
```

## Запуск

Запустите приложение с помощью:
```bash
npm start
```

Приложение будет доступно по адресу: **http://localhost:3000**

## Особенности

✅ Получение данных из The Cat API  
✅ Отзывчивый дизайн (адаптивен под мобильные устройства)  
✅ Красивые карточки с изображениями котов  
✅ Информация о породе котов  
✅ Описание каждой породы  
✅ Индикатор загрузки  
✅ Обработка ошибок

## Технологии

- **Backend**: Node.js, Express.js, Axios
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **API**: The Cat API (https://thecatapi.com)

## API Endpoints

### GET /api/cats
Возвращает массив котов с изображениями и описаниями пород.

Пример ответа:
```json
[
  {
    "id": "abc123",
    "url": "https://...",
    "breed": "Bengal",
    "description": "Бейсегал это..."
  }
]
```
